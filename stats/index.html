This page fills itself in every hour from GoatCounter, once the deploy can read it:

  1. In GoatCounter (megazine.goatcounter.com), open your name menu → API and create a key that can read statistics.
  2. On GitHub, in megazinehq/megazinehq.github.io → Settings → Secrets and variables → Actions, add it as GOATCOUNTER_TOKEN.
  3. The next hourly deploy (or any push) brings the numbers in.
